# 舟声 · 明日方舟剧情配音

Windows 桌面应用。只读取所选窗口画面，并在你点击录音后采集系统播放的声音；不读取、修改或解包游戏文件，不访问游戏进程内存，不模拟游戏操作。

## 启动

本项目仅支持 Windows。先安装 Python 3.13，并确认系统有可用的中文语音。克隆仓库后，在 PowerShell 中运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\启动演示.bat
```

首次启动时，中文 OCR 所需模型可能需要下载。实时 OCR 和系统中文配音可先独立使用；录音转写、角色声音克隆与训练需要在“设置与帮助”中安装本地语音引擎。首次安装会下载数 GB 依赖和模型，训练还需要兼容的 NVIDIA GPU。模型、运行环境、录音和本机设置均保存在项目目录中，不随源码仓库分发。修改程序后，需要关闭旧窗口再重新启动。

## 实时配音

1. 选择“明日方舟”窗口，点击“开始自动配音”。程序最小化后，回到游戏查看剧情。
2. F8 可开始或暂停配音。切回其他窗口时暂停抓图，返回游戏自动继续。
3. 自动识别整个窗口中的台词，包括上方、中间、底部的文字及连续多行。
4. 角色声线按说话人名称自动匹配；没有可用角色录音时使用本机中文旁白。界面不再提供声线选择或批量上传。
5. 可载入截图测试，也可修改识别结果后重新朗读。

识别采用常驻 Windows 中文 OCR 定位文字，再用 RapidOCR 复核文字区域。静止画面复用识别结果。自动配音按稳定短句增量朗读：前面的完整短句在连续两次识别中得到确认后即可开始合成，无需等整段文字出现；末尾没有标点的文字稳定约 0.55 秒后补读。朗读时继续识别并预生成后续短句，按顺序播放，翻页后清除旧队列和过期结果。它仍需等待短句完整和语音合成，尚非逐字即时发声；较长无标点文本仍需等待稳定。

## 角色录音室

1. 在游戏中打开角色语音页，关闭背景音乐和其他应用的声音。
2. 在“录角色声音”填写角色名，选择录音语言。角色名应与剧情中显示的名字一致。
3. 点击“开始录音”，回到游戏播放几句角色语音。按 F9 停止，也可返回 App 点击停止。
4. 程序采集当前默认扬声器/耳机的回环声音，会自动去除长静音、切分片段，并转写语音原文。
5. 选中表格中的片段，点击“试听选中片段”；双击原文可修正人名和错字。已有一段 3–10 秒、文字完整的录音，即可点击“直接试听”：自动连接引擎并预热，不用先训练或进入设置。
6. 训练是可选的：累计至少 **30 秒有效录音**后，展开“可选：进一步训练角色”，选择默认 **2 轮快速训练**，或 8 轮完整模式。有效时长只统计有文字、文件存在、未破音的片段，不计静音或空白转写。30 秒是素材门槛，不是训练耗时；首次提取特征和模型加载仍可能需要数分钟，音色效果取决于样本质量。
7. 程序在两个模型文件都生成后才标记为已训练。若随后试听报错，已保存模型仍然保留，不用重录或重训。状态提示、阶段进度和详细日志分别显示。

录制的是当前输出设备的全部声音，不是单独的游戏音轨。因此录制时应关闭背景音乐、浏览器视频、语音聊天等。单次录音最长 10 分钟；音色相似度取决于录音清晰度、背景声音和原文准确度。请只采集你有权用于 AI 合成的声音。

训练期间暂停剧情配音。训练可以取消，已录制的声音会保留。保存参考录音与模型微调是两个不同阶段，界面会显示实际状态。

## 设置与帮助

默认引擎安装在本项目的 `engines/GPT-SoVITS`，训练 Python 位于 `engines/runtime`，与主界面的 Python 独立。首次安装需下载数 GB GPU 依赖和预训练模型。可使用界面的安装按钮补全缺失文件，也可指定已有 GPT-SoVITS 环境。

转写使用本地 faster-whisper small；角色训练使用 GPT-SoVITS v2，默认 2 个训练轮次、批大小 2。安装路径和原始日志放在折叠区域，日常只需关注状态和当前任务。本机为 8 GB 显存的 RTX 5060 Laptop，已安装 CUDA 12.8 对应的 PyTorch。

遇到 `No module named 'resampy'` 等声音依赖问题，点击“修复声音依赖”。该操作补齐音频库并实际测试 48 kHz → 16 kHz 的重采样，不更改角色样本或已训练的模型。本次已修复该错误，并用用户现有阿米娅模型及实际录音验证新台词合成成功。

界面改为奶白与浅绿色，使用“米米子”“凯尔希炭”头像装饰。来源及权利说明见 [素材来源](assets/SOURCES.md)。

`F8/F9` 为系统快捷键，若被其他应用占用仍可使用界面按钮。系统输出设备切换后，请停止当前录音再重新开始。

## 数据与验证

- `voice_profiles/recordings`：原始系统声音录音。
- `voice_profiles/characters`：分段录音与各角色的训练结果。
- `models`、`engines`：本地模型和独立运行环境。
- `.demo_cache`：临时画面、语音缓存、测试输出与引擎日志。
- `app_settings.json`：本地引擎路径设置。

以上目录和本机设置已从 Git 提交中排除。请勿在 Issue 或 Pull Request 中上传角色录音、训练模型、账号信息或其他无权公开的数据。

本次三张实际剧情截图回归测试：跨行旁白、短台词、角色标签均通过；预热后识别与复核约 172–290 ms，系统短句生成约 83 ms。旧版相同机器单次识别约 1695 ms、系统短句生成约 916 ms。这些为有限样本的本机测量，不代表所有场景的延迟或准确率，且不包含文字稳定等待、首次加载和角色模型生成时间。

另使用 75.91 秒系统合成测试语音完成了本地转写、特征提取、SoVITS/GPT 各一轮真实训练、模型保存与加载，并成功生成未参与训练的新台词。角色合成关闭音频缓存实测首次约 11.9 秒、预热后另一句约 3.0 秒；这与系统默认声线的耗时不同。界面连接角色引擎时会提前预热，重复台词可命中音频缓存。此测试验证功能链路，不代表真实干员录音的音色相似度或八轮训练质量。录音设备枚举、静音切分已验证；没有替用户录制实时游戏声音。

未解决的边界：纯视觉无法可靠还原所有临时称谓与真实角色的关系；当前未接入完整剧情脚本索引。OCR 仍可能误读特殊字体、复杂背景和专有名词；模型分数不是准确率保证。角色克隆及训练的速度、音质需要以实际录音试听为准。

本轮另使用 **32.9 秒**合成测试语音完成 SoVITS/GPT 各 **2 轮**快速训练。增量文本、30 秒门槛、重复抑制等 9 项回归测试通过；播放队列验证了前句播放时预生成后句、后句不打断前句，以及停止后丢弃过期生成结果。没有自动播放测试声音。

后续计划（用户选择下一版再做）：剧情上下文记忆、人物与地名读音词典、情绪分析及与配音模型的表达控制。目前未下载语言模型或发送剧情到云端，也未将规则处理描述为剧情理解。

开发验证：`.venv\Scripts\python.exe -m unittest test_app test_story_matcher`。`verify_runtime.py` 可依次传入三张本地截图，测量识别和系统配音；`verify_training.py` 使用临时系统合成语音检查真实训练链路，不会添加测试角色到角色库；`verify_character.py` 加载该测试模型并验证两句合成，不播放声音。`render_preview.py` 可用自制示例画面生成界面预览图。
