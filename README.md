# Voice of Terra · 泰拉之声

## 功能

Voice of Terra 是在浏览器中阅读和收听《明日方舟》剧情的非官方同人项目。博士，故事已经在这里铺开了：[打开泰拉之声](https://luoul-123.github.io/voice-of-terra-for-arknights/)即可阅读全部收录剧情。

凯尔希正在为 SideStory **《时间啊，向前！》** 讲述往事。已上线的段落会标出“凯尔希有声”，其余剧情也能阅读、看立绘与 CG、听背景音乐。后续只使用凯尔希音色，逐步补充有声章节。

| 功能 | 说明 |
| --- | --- |
| 剧情剧场 | 阅读台词、选择分支，查看背景、角色立绘与 CG |
| 凯尔希配音 | 已上线的章节可逐句播放，也能开启随身听连续收听 |
| 剧情目录 | 按剧情类型、实装时间浏览，支持搜索与跨故事跳转 |
| 阅读设置 | 深色或浅色主题、逐字显示、配音与音乐音量、播放速度 |
| 存档 | 进度保存在当前浏览器，网页更新后仍可继续阅读 |

## 用户安装教程

在线阅读**无需安装**，直接打开 [Voice of Terra 网页](https://luoul-123.github.io/voice-of-terra-for-arknights/)。点右上角的目录选择故事；有“凯尔希有声”标记的章节可以收听，其他章节可以阅读。设置里可以切换黑白主题。存档只保存在当前浏览器；换设备或清除网站数据后不会自动同步。

开发者可以从 [GitHub 下载源码 ZIP](https://github.com/luoul-123/voice-of-terra-for-arknights/archive/refs/heads/main.zip)。本地保留的语音模型和生成工具用于制作新音频，不是读者使用网页的前置条件。

## 剧情目录

以下目录以**故事组**为单位。两种顺序均依据国服首次实装日期；点故事标题会在同一个主网页中打开对应章节目录。日期来自当前剧情档案快照，后续会随数据更新。

## 架构和目录

主网页由 GitHub Pages 托管，浏览器读取剧情文本、立绘、CG 与音乐。凯尔希配音在本地提前生成 MP3，发布到独立的 [音频 Pages 分站 vot-audio-20261101](https://github.com/luoul-123/vot-audio-20261101)；主网页依据音频索引读取对应分站，读者始终使用同一个主网址，不需要租 GPU 服务器。后续故事可以使用新的音频分站，每个分站须遵守 GitHub Pages 的 [1 GB 站点上限](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)。

| 路径                                      | 内容                                                     |
| ----------------------------------------- | -------------------------------------------------------- |
| `web/pages/` | 主网页、剧情目录、音频清单与分站映射 |
| `web/lib/` | 剧情解析、分支场景与播放逻辑 |
| `web/scripts/` | 静态站点检查、目录生成与音频生成脚本 |
| `web/backend/` | 仅供本地制作配音的语音服务 |
| `web/app/` | 早期本地网页代码；读者无需运行 |
| `engines/`、`models/`、`web/.voice-data/` | 本地语音引擎、凯尔希模型与生成缓存；不提交到源码仓库 |
