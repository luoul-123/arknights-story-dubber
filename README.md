# 泰拉之声 · 明日方舟有声视觉小说

在浏览器里看剧情、听角色对话和旁白，也可以切换到「随身听」连续收听。

网站直接读取剧情脚本，呈现背景、人物立绘、CG、底部对话框和分支选项。用户无需截图识别、安装桌面插件或训练角色；也可自愿上传一段录音，将全部文本改为统一声音朗读。

## 已实现

| 功能 | 行为 |
| --- | --- |
| 视觉小说阅读 | 章节目录、背景 / 立绘 / CG、逐字显示、分支选择、对话回顾 |
| 自动配音 | 已发布角色使用专属音色；其余角色、NPC、未知说话人自动使用通用中文声音 |
| 有声旁白 | 旁白自动朗读，无需读者另行设置 |
| 随身听 | 每句播放完自动继续；打开目录、回顾、设置、工作室仍持续播放，音量和语速即时调整 |
| 段落衔接 | 读完后确认进入下一段；保留行动前 / 行动后顺序，随后进入下一关 |
| 剧情分类 | 主线、SideStory、故事集、个人密录及其他；按章节、活动、干员搜索 |
| 实装时间线 | 按国服首次实装日期排序，可筛选年份、切换升降序 |
| 站点默认声音 | 普通角色使用佩丽卡 / 男管理员，重要角色使用预设声线，旁白使用佩丽卡 |
| 我的统一朗读声 | 上传 3–10 秒录音，自动识别原话，确认后角色台词与旁白全部使用该声音；可切回默认 |
| 立即跳句 | 中断当前播放并进入下一句；旧合成请求晚到也不会串音 |
| 剧情缓存 | 目录和打开过的章节保存在本机；主来源失败时尝试备用来源，缓存过期也可先阅读 |
| 阅读进度 | 手动存档独立持久保存，刷新优先恢复手动存档；没有手动存档时恢复自动进度 |
| 剧情音乐 | 前奏 / 循环 / 停止按脚本切换，音乐和配音音量独立调节 |
| 立绘差分 | 精确读取表情与姿态标识，支持左右中人物槽位与说话焦点 |
| 管理员工作室 | 按干员名导入一段游戏语音，或上传短录音，试听并统一发布音色 |
| 免训练优先 | GPT-SoVITS 预训练模型 + 参考语音；单独训练仅作为可选优化 |

普通干员共用基础模型，只导入游戏已有的短参考录音，不为每个角色单独训练；模型保存在后端，浏览器不会下载模型。

普通读者只需选择章节。NPC 和旁白无需逐个配置；管理员可补充或替换专属音色；当前阿米娅、凯尔希、陈、杜宾均使用预设参考声线。通用声音不等于角色原声，游戏已有语音仅作为合成新台词的参考。

## 在这台电脑使用

1. 双击根目录的 **启动网页版.bat**。
2. 浏览器打开后进入剧情，或点击右上角 **随身听**。
3. 使用结束后双击 **停止网页版.bat**。

本机地址为 http://127.0.0.1:5173/ 。启动器自动准备本地服务密钥，并打开本地管理员会话；只监听本机，不需要购买服务器或域名。

阅读时点击可补全文字，再次点击推进；底部跳过按钮可以立即停止当前配音并跳到下一句。设置中可以关闭逐字显示。

## 我的朗读录音室

右上角打开录音室 → 上传一段 3–10 秒、最多 10 MB 的清晰录音 → 校对自动识别的原话 → 点击“用这个声音朗读全部文本”。这会覆盖所有角色与旁白的声音，无需训练。点击“默认角色配音”即可恢复预设分配。录音按登录用户隔离，选用模式保存在当前浏览器。

## 从 GitHub 首次安装

当前验证环境为 Windows。需要 Node.js 22.13+、Python 3.11+ 和 Git。基础阅读、通用角色及旁白使用 Windows 已安装的中文语音，专属角色克隆另需 GPT-SoVITS 引擎与合适的 NVIDIA GPU。

在 PowerShell 中运行：

~~~powershell
git clone https://github.com/luoul-123/arknights-story-dubber.git
cd arknights-story-dubber
py -3 -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
cd web
npm ci
cd ..
./启动网页版.bat
~~~

### 可选：专属角色音色

~~~powershell
./.venv/Scripts/python.exe web/backend/setup_engine.py
~~~

安装器将引擎、独立 Python 和预训练模型下载到本项目目录，首次需要下载数 GB 文件。仅准备录音转写模型可追加 --asr-only。

之后打开网站的「音色工作室」：输入干员名 → 导入干员语音 → 试听 → 发布。也可上传一段清晰的 3–10 秒参考录音并校对对应文字。无需给每个角色单独训练；未发布专属音色的角色仍然可以使用通用声音。

仓库不包含本机录音、角色模型、缓存或服务密钥。阿米娅、杜宾、佩丽卡和男管理员的本机音色不会随 GitHub 克隆分发。管理员可在音色工作室发布模型，再指定全站默认女声、男声和旁白。

默认角色声音先查干员档案中的性别，再匹配说话人名称中明确的男女称谓；信息不明时使用默认女声，不推测隐藏身份。已有专属音色优先。

## 架构与目录

浏览器播放剧情 → 网站服务端代理 → 本机语音服务 → GPT-SoVITS 或 Windows 中文语音 → 音频缓存与浏览器播放。

- web/app：视觉小说界面、音色工作室、剧情与配音 API。
- web/lib：剧情脚本解析、分支场景和可中断音频播放器。
- web/backend：语音合成、默认旁白 / NPC 配音、素材导入、转写及可选训练。
- web/tests：剧情与音频测试、真实浏览器检查。
- engines/、models/、web/.voice-data/：本机引擎和语音数据，均不提交。

旧桌面 UI、屏幕采集、OCR、桌面启动入口及旧界面截图已移除。

## 开发与验证

~~~powershell
cd web
node --test tests/core.test.mjs
../.venv/Scripts/python.exe -m unittest discover -s backend -p "test_*.py"
npx tsc --noEmit
npm run build
~~~

本机网站启动后，可运行 node tests/browser-smoke.mjs 验证后台连续播放、暂停、跳句和分支等待；node tests/browser-navigation.mjs 验证面板内持续播放、音量 / 语速不中断、分类时间线及 0-1 → 0-2 确认衔接。node tests/browser-reader-voice.mjs 验证真实上传识别、统一声音及恢复默认（需本机佩丽卡参考素材）。这些检查使用隐藏 Edge，测试全程静音，顺序执行。

## 当前范围

- 已验证桌面 Edge 切换到其他标签页后的连续播放；手机锁屏与系统媒体按钮尚未实机验证。
- 未配置默认模型时使用 Windows 中文系统声音；配置并发布默认模型后，通用角色和旁白也走 GPT-SoVITS。Linux 尚未实机验证。
- 专属音色首次加载模型可能较慢，之后的预热请求及缓存命中更快；尚未实现整章预先生成。
- 当前目录包含上游提供的 2,061 段剧情，491 组。时间线覆盖该目录；活动分周开放的精确关卡日期尚未逐项补全，默认使用所属活动首发日期。详见 [实装时间来源](web/docs/catalog-sources.md)。
- 已实现常用剧情演出；已支持按脚本切换完整立绘差分与背景音乐，音乐和配音独立调节；复杂连续动画及部分特殊指令尚未完整支持。
- 剧情目录与首次打开的章节通过本机后端读取上游资源，支持系统代理、GitHub / jsDelivr 来源回退及磁盘缓存；缓存过期时先返回已有内容，再后台更新。图片仍按需联网读取。本机版本尚未作为公网服务部署；生产部署需配置真实身份认证、服务密钥及语音后端。
