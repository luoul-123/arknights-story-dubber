# 默认声音素材与训练

默认声音由站点管理员统一准备、发布和指定，普通读者无需上传素材或训练。读者也可自愿上传短录音，覆盖全部台词和旁白为统一声音。当前本机默认采用参考音色模式，共用基础模型。专属角色音色优先，其他角色按干员档案性别或明确称谓分配默认男女声；无法判断时使用默认女声。旁白单独指定。

来源：[Warfarin 佩丽卡](https://warfarin.wiki/cn/operators/perlica)、[Warfarin 管理员](https://warfarin.wiki/cn/operators/endministrator)。男性管理员使用 chr_0002_endminm 资源；佩丽卡为 chr_0004_pelica。页面文字与独立普通话语音逐条对应，ASR 仅辅助核验，不用错误转写覆盖角色专名。28 条原始录音均通过削波检测。

男声参考取自完整 16.509 秒录音的开头 5.2 秒，完整句为“我听见了她的声音，像是梦中的呢喃。”句末与下一句之间有静音。完整原录音保留用于训练；派生参考标记 referenceOnly，不重复计入训练素材。

## 管理方式

- backend/import_voice_dataset.py 是本机管理员导入工具：输入包含路径、原文、来源与参考标记的 JSON 清单，保存 32 kHz 单声道录音，按原文件哈希去重。
- 训练走项目已有 GPT-SoVITS v2 流程。训练与合成共用 GPU 锁，排队执行。
- 音色工作室发布模型后，在“全站默认声音”选择女声、男声和旁白并保存。设置存于 .voice-data/default-voices.json；改配置或重新发布模型后，浏览器音频缓存版本会变化。
- 录音、模型、试听音频及默认映射都是本机运行数据，不进入 Git。首次克隆仓库的管理员需要自行导入与发布。

这些是较小规模的训练素材，尤其男声多数录音不足 3 秒。真实模型能合成音频不代表相似度、情绪表现已经验收；还需要人工试听。详细运行结果见 [验证记录](../VALIDATION.md)。

## 角色数量与体积

普通干员使用游戏已有的 3–10 秒参考录音，共用同一套 GPT-SoVITS 基础权重，不为每名角色增加模型。当前杜宾参考 WAV 约 0.58 MiB，角色模型增量为零；当前一个训练角色的最终 GPT + SoVITS 权重约 229 MiB，训练中间文件另计。因此不批量训练全部干员。佩丽卡、男管理员和原有阿米娅的训练模型保留备用；按照最终轻量化方案，当前这三者也发布为 reference 模式，不加载各自训练模型。

推理后端切换当前 GPT / SoVITS 权重，不建立全角色模型常驻集合。浏览器不会下载模型，音频对象缓存最多 24 条，并预取下一句。后端按需合成的 WAV 磁盘缓存会随阅读内容增加；它不等于浏览器内存或显存。游戏录音只能直接播放已有台词，合成新的剧情台词仍需要共享模型与推理算力。

当前已发布参考声线：阿米娅、杜宾、凯尔希、陈、佩丽卡、男管理员，使用同一套基础权重。凯尔希参考 4.43 秒，陈参考 3.00 秒；均直接导入游戏语音，没有训练。
